# bind-message-bus

[![Release](https://img.shields.io/packagist/v/icanboogie/bind-message-bus.svg)](https://packagist.org/packages/icanboogie/bind-message-bus)
[![Downloads](https://img.shields.io/packagist/dt/icanboogie/bind-message-bus.svg)](https://packagist.org/packages/icanboogie/bind-message-bus)

The **icanboogie/bind-message-bus** package binds [icanboogie/message-bus][] to [ICanBoogie][].



#### Installation

```shell
composer require icanboogie/bind-command-bus
```
